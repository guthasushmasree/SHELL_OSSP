
Main Loop – while(1) continuously runs the shell.

Display Prompt – Displays myshell> before every command.

Read User Input – Reads characters directly from the keyboard.

Exit Condition – Typing exit terminates the program.

Keyboard Input – getch() captures one character at a time.

Backspace – Allows the user to delete the previously typed character.

Enter Key – Pressing Enter completes the command.

Input Buffer – input[] stores the characters entered by the user.

Multi-Character Commands – Commands such as hello, help, and exit are supported.

User Interaction – The program continuously accepts commands and displays appropriate responses.
